# Game Catalogue

Game Catalogue is a closed-source Windows desktop application for browsing DLPS, SUPERPSX, PFS/LZ4/FPKG, and exFAT game catalogues.

## Download

Download the latest Windows executable from the [Releases](https://github.com/kerrdec97/Game-Catalogue/releases/latest) page.

## Distribution

This repository distributes compiled releases and documentation only. The application source code is closed source and is not included.

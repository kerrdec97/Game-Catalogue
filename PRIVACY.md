# Game Catalogue Privacy Notice

Effective date: 19 September 2026

Game Catalogue does not require an account and does not include developer-run
analytics, advertising, telemetry, or crash-reporting services. The developer
does not receive the library, favourites, settings, logs, searches, or other
application data stored on your computer.

## Data stored locally

Game Catalogue stores catalogue datasets, favourites, settings, logs, cached
content, and automatic backups locally under `%APPDATA%\DLPS Ripper` on
Windows. This legacy folder name is retained so existing installations keep
their data after the application rename.

You can open this folder from Settings > Application Data. Close the
application and delete that folder to remove its locally stored data.

## Network requests

When you load or update a catalogue, view cover art, or use an external action,
the application may connect directly to independent services, including:

- DLPSGame and DownloadGamePS3 catalogue endpoints;
- SUPERPSX catalogue endpoints;
- the PFS/LZ4/FPKG catalogue service;
- the Pippo exFAT catalogue on GitHub Pages or GitHub raw content;
- image hosts and the wsrv.nl image proxy referenced by catalogue data;
- Google Fonts for the Inter typeface; and
- YouTube, GitHub, Ko-fi, download hosts, or other external links that you
  choose to open.

Those third parties receive ordinary connection information such as your IP
address, browser or application user-agent information, request time, and the
requested URL. Their own privacy policies and terms apply. Game Catalogue does
not control those services.

## Download links and catalogue content

Catalogue metadata, images, and links originate from third parties. Game
Catalogue normalises and displays that information locally; it does not upload
your local application data to the developer.

## Changes

Material changes to this notice will be published in the Game Catalogue GitHub
repository and accompanying release documentation.
